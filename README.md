# Better with Aether Instance

Combines [packwiz](https://packwiz.infra.link/) and [unsup](https://git.sleeping.town/exa/unsup) to provide a single self-updating instance which can be managed from a git repository.

## How to update

- Clone the repository (for example in Github Desktop).
- Use ``packwiz url add "Mod Name" <url>`` [--force]```to add mods.
- Use ``packwiz refresh`` to refresh packwiz.

- Add, commit, and push.
- **Pushes are accepted instantly!** Be careful.
